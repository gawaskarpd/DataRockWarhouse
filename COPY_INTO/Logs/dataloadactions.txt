2. ROOT CAUSE ANALYSIS
-------------------------------------------------------------------------------
- The Snowflake VS Code extension (snowflake.snowflake-vsc v1.41.0) does NOT
  execute raw PUT statements typed in a .sql file. Verified by inspecting the
  extension's bundle: it has no code path for PUT-in-SQL; it only supports PUT
  through its Stage Operations UI (right-click stage -> "Snowflake: PUT to
  Stage").
- When typed PUT SQL is executed anyway, the extension submits the statement
  and then tries to fetch a query result by query ID (it runs DESC RESULT
  after every statement). A PUT produces no retrievable persisted result, so
  the fetch returns "Query result expired" (SQL error 000710). This is the
  same limitation that exists in Snowsight worksheets.
- The file path was checked and is correct: both
  C:\Users\Gawaskar\OneDrive\Desktop\train.csv (1.94 GB) and
  C:\Users\Gawaskar\OneDrive\Desktop\train_100_records.csv (86 KB) exist.
  The path was NOT the cause of the error.
